01Foundations

Typography

Two voices. Display copy is .font-dm-sans (DM Sans, the page's only web font, almost always at weight 300 with tracking-tighter); every other line falls to the Play-CDN font-sans stack, overridden in the config to the system UI face (ui-sans-serif, system-ui, -apple-system…). Index chips and handles use Tailwind's font-mono. Sizes are the Tailwind utilities declared on each element, widest breakpoint first.
